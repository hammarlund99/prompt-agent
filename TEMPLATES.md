# Prompt Templates by Task Type

## 1. Analysis Template

```
Analyze [SUBJECT] from the perspective of [DIMENSION/ANGLE].

Context:
- Background: [relevant background]
- Constraints: [any limitations or boundaries]
- Format needed: [desired output format]

Success criteria:
- [criterion 1]
- [criterion 2]
- [criterion 3]

Please provide:
1. [specific aspect 1]
2. [specific aspect 2]
3. [specific aspect 3]
```

## 2. Code Generation Template

```
Write [LANGUAGE] code that [FUNCTIONALITY].

Requirements:
- Framework/version: [if applicable]
- Key features: [feature list]
- Constraints: [performance, size, etc.]
- Error handling: [how to handle errors]

Input: [specify input format/example]
Output: [specify output format/example]

Style preferences:
- Naming: [conventions]
- Comments: [level of commenting]
- Testing: [include tests? yes/no]
```

## 3. Writing Template

```
Write [CONTENT TYPE] about [TOPIC] for [AUDIENCE].

Parameters:
- Tone: [formal/casual/humorous/etc.]
- Length: [word count or duration]
- Format: [structure/sections needed]
- Purpose: [what should reader do/think/feel]

Key points to cover:
- [point 1]
- [point 2]
- [point 3]

Style examples:
[Provide 1-2 examples of desired tone/style]
```

## 4. Problem-Solving Template

```
I need help solving: [PROBLEM STATEMENT]

Current situation:
- What I've tried: [previous attempts]
- What worked: [any successes]
- What didn't work: [failures]
- Current blockers: [what's preventing progress]

Constraints:
- [constraint 1]
- [constraint 2]

Success looks like: [specific outcome]

Please provide:
1. Root cause analysis
2. [X] potential solutions
3. Pros/cons for each
4. Recommended next step
```

## 5. Brainstorming Template

```
Generate [NUMBER] ideas for [GOAL/CHALLENGE].

Context:
- Target: [who/what is this for]
- Constraints: [budget, time, resources, etc.]
- Similar successful examples: [reference points]
- Criteria for evaluation: [how to judge ideas]

Must include:
- [requirement 1]
- [requirement 2]

Should avoid:
- [anti-pattern 1]
- [anti-pattern 2]

Format: [bullet points/detailed descriptions/etc.]
```

## 6. Learning Template

```
Explain [CONCEPT] in a way that's suitable for someone with [BACKGROUND].

Current understanding: [what they already know]
Specific questions:
- [question 1]
- [question 2]

Preferred learning style:
- Examples: [yes/no, what kind]
- Analogies: [yes/no]
- Step-by-step: [yes/no]
- Visual descriptions: [yes/no]

Use cases: [practical applications]
Common misconceptions: [what not to teach them]
```

---

## How to Use These Templates

1. **Copy** the template relevant to your task
2. **Fill in** all bracketed sections with your specific details
3. **Review** for completeness using the CAPTURE-CLARIFY-CONTEXTUALIZE-STRUCTURE-VALIDATE framework
4. **Run** your refined prompt through your AI assistant
5. **Iterate** if needed based on results

**Pro tip:** The more detail you provide in the template, the better your results will be.
