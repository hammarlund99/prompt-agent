# Prompt Agent 🎯

A personal prompt engineering assistant designed to help you craft exceptional prompts for any task. Before you tackle any challenge, let your prompt agent help you formulate the perfect prompt.

## Purpose

The Prompt Agent elevates your prompt engineering skills by:
- **Analyzing** your initial request and identifying gaps or ambiguities
- **Refining** your prompt for clarity, specificity, and effectiveness
- **Optimizing** for the AI model and task type
- **Validating** that your prompt will yield the best results

## Core Workflow

```
Your Initial Idea
    ↓
Prompt Agent Analysis & Refinement
    ↓
Optimized Prompt (Ready to Execute)
    ↓
Task Completion
```

## Quick Start

Before starting ANY task, invoke your prompt agent:

```
@prompt-agent: [Your initial task description]
```

The agent will help you:
1. ✨ Clarify your objectives
2. 🎯 Define success criteria
3. 📋 Structure your request optimally
4. 🔍 Identify missing context or constraints
5. 🚀 Generate your final, powerful prompt

## Components

- **prompt-engineering-framework**: Core principles and methodologies
- **prompt-templates**: Pre-built templates for common task types
- **evaluation-metrics**: How to measure prompt effectiveness
- **examples**: Real-world prompt refinements

## Key Principles

- **Clarity**: Eliminate ambiguity
- **Specificity**: Include concrete details and constraints
- **Context**: Provide relevant background and constraints
- **Structure**: Organize information logically
- **Validation**: Verify the prompt achieves intended results
